## 实验 #1 — AVX2 SIMD 优化

- **时间**: 2026-04-09 00:05:00
- **方向**: 逐行调用 memcpy 有函数调用开销，使用 AVX2 intrinsic 直接处理，一次 32 字节
- **修改**: nv12_crop.c
  - 创建初始文件（朴素的 memcpy 实现）: 56566.2 ns
  - 使用 `_mm256_loadu_si256` / `_mm256_storeu_si256` 替代 memcpy
  - 主循环处理 32 字节对齐部分，memcpy 处理尾部
- **结果**:
  - avg_ns/op: 56566.2 → 54176.7 ns (-4.2%, ~2389 ns 改善)
  - bandwidth: 22.76 → 23.76 GB/s (+4.4%)
  - 正确性测试: PASSED
- **决策**: ✅ 保留
- **原因**: 指标有改善，虽然幅度不大但有效
- **下一步建议**:
  - 尝试循环展开，减少分支预测失败
  - 尝试非临时存储指令 (_mm256_stream_si256) 绕过 CPU 缓存
  - 尝试预取指令 (_mm_prefetch) 提前加载数据
  - 分析为什么只有 4.2% 改善（memcpy 本身已经很优化）

## 实验 #2 — 4x AVX2 循环展开

- **时间**: 2026-04-09 00:10:00
- **方向**: 循环展开减少分支开销，每次迭代处理4个AVX2向量（128字节）
- **修改**: nv12_crop.c
  - Y平面和UV平面内层循环：4x展开
  - 保留剩余32字节块处理和尾部memcpy
- **结果**:
  - avg_ns/op: 54306.1 ns (vs 54176.7 ns 基准，+0.24%)
  - bandwidth: 23.71 GB/s (vs 23.76 GB/s 基准)
  - 正确性测试: PASSED
- **决策**: ⚪ 保留（噪声范围内持平）
- **原因**: 无显著改善，表明内存带宽是瓶颈而非循环开销
- **下一步建议**:
  - 尝试非临时存储 (_mm256_stream_si256) 绕过缓存
  - 尝试预取指令 (_mm_prefetch) 隐藏内存延迟
  - 考虑更激进的向量化（如AVX-512）或多线程
  - 分析内存访问模式是否优化

## 实验 #3 — 非临时存储优化

- **时间**: 2026-04-09 00:15:00
- **方向**: 使用 `_mm256_stream_si256` 绕过 CPU 缓存直接写入内存，避免缓存污染
- **修改**: nv12_crop.c
  - Y平面和UV平面：所有 `_mm256_storeu_si256` 替换为 `_mm256_stream_si256`
  - 添加 `_mm_sfence()` 确保流存储完成
- **结果**:
  - 正确性测试: ❌ 段错误 (Exit code 139)
- **决策**: ❌ 回退
- **原因**: `_mm256_stream_si256` 要求目标地址 32 字节对齐，但 dst_y/dst_uv 不保证对齐
- **下一步建议**:
  - 尝试软件预取 (`_mm_prefetch`) 提前加载数据
  - 尝试对齐检测 + 条件流存储（增加复杂度）
  - 考虑修改 API 要求对齐的 dst_stride
  - 分析内存访问模式，尝试行间预取

## 实验 #4 — 软件预取优化

- **时间**: 2026-04-09 00:20:00
- **方向**: 使用 `_mm_prefetch` 提前加载后续行数据到 L1 缓存，隐藏内存延迟
- **修改**: nv12_crop.c
  - Y平面和UV平面循环：在处理第 N 行时预取 N+2 和 N+4 行
  - 使用 `_MM_HINT_T0` 预取到 L1 缓存
- **结果**:
  - avg_ns/op: 56913.9 → 55111.2 ns (-3.17%, ~1803 ns 改善)
  - bandwidth: 22.62 → 23.36 GB/s (+3.3%)
  - 正确性测试: PASSED
- **决策**: ✅ 保留
- **原因**: 预取有效隐藏了内存延迟，指标有改善
- **下一步建议**:
  - 尝试调整预取距离（N+1, N+3 或 N+2, N+3）
  - 尝试 `_MM_HINT_NTA` 非临时预取（避免缓存污染）
  - 尝试组合预取 + 其他优化
  - 分析预取效果是否达到极限

## 实验 #5 — NTA 预取策略

  - 正确性测试: PASSED

- **原因**: NTA 与 T0 预取效果相当，预取优化已到极限
- **下一步建议**:
